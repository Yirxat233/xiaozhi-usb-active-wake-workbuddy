# Firmware release

Tag: `wb4`

The GitHub Release contains the merged 16 MB-flash image and the complete firmware source archive. Flash the merged image at address `0x0`; doing so resets NVS. To preserve Wi-Fi and activation data, build locally and flash only `xiaozhi.bin` at `0x20000`.
